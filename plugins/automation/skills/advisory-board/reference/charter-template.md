# Board charter template

Save as `.claude/board/<output-type>.md` (Claude Code) or `board/<output-type>.md`
(any project), or paste it into a Claude Project's or ChatGPT Project's
instructions. Keep it under a page. The board reads all of it on every run.

```markdown
# Board charter: <output type, e.g. "AEO comparison pages">

Last updated: <date> by <name>

## The reader
<Who reads this, in what situation, and what they should do afterwards.>

## What good looks like
- <A rule, with the reason.> Example: "<quote from a version you liked>"
- …

## What gets sent back
- <A correction you made before, with the reason.> Example: "<quote>"
- …

## Hard lines (a blocker, every time)
- <e.g. no number without a source link>
- <e.g. no finding without the query or row count it came from>
- <e.g. never name a client without approval>
- <e.g. no promises about rankings or AI visibility>

## The board
| Role | Mandate |
|---|---|
| The reader | … |
| The fact-checker | … |
| <role> | … |

## Sources the fact-checker may use
- <where the true numbers live, in a form the fact-checker can open: an export, a sheet, a folder>
```

## Keeping it alive

Every time a human overrules the board, or catches something the board
passed, add one line to "What gets sent back" or "Hard lines". After a few
weeks the charter holds your actual standards, and the board stops giving
generic advice.
